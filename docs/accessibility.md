# アクセシビリティ — 目標と検証範囲

**このstarterはWCAG適合を認定・保証するものではありません。** 自動試験と手動確認を分けます。

## 実装していること

状態15語・ゲート6結果をapp/states.jsの固定した単色の形で識別し、state・kind・ownerを文字でも表示。色はレーンへ使い、レーン名も表示。Current/Ready/Selection/Focusを別形状で表示します。
TaskとGateは形と記号、関係は線種・矢印・端点・文字で識別します。
ノードはキーボードのEnter/Spaceで選択、方向キーで近いノードへ移動できます。
一覧表示からも全ノード・詳細・関係先へ辿れます。設定dialogはEscで閉じ、起点へfocusを戻します。
モーションは使わず、reduced-motion/forced-colors用の補助スタイルを用意しています。

配色の解決時に本文・補助文字は4.5:1、重要境界は3:1を下回るtokenを補正します。
高コントラスト指定では本文・補助文字の目標を7:1にします。
これはcanvas/surfaceという基準背景に対する数値検証であり、あらゆるピクセル合成や視認性を保証するものではありません。

## 小画面

375pxを必須確認幅とし、320pxも回帰試験で追加確認します。盤面の座標は固定し、同じ座標のカメラをパン・ズームして移動します。
文章・設定・詳細は一列へ。読める倍率と一覧表示を用意し、全体を潰して375pxへ縮めることを標準にしません。
主要操作はおおむね44px、補助操作も24px以上を目標にします。
盤面は全体表示へ縮小すると文字やターゲットも縮小するため、操作には「読める倍率」または一覧を使います。

## まだ人間が確認すること

実機iOS/Android、VoiceOver/NVDA等、ブラウザー200/400%拡大、色覚の多様性、長文の全表示、混雑したグラフと指操作。
数値テストとChromiumテストだけでこの確認に代えません。

## v0.3の追加

現在地の分節リングとReadyの4方向印は外付けで、色だけに依存しません。全体表示では印の画面寸法を下支えし、低倍率の文字・関係線を段階的に減らします。現在地の件数と巡回ボタン、焦点の文字案内を表示します。375pxの選択詳細は下部固定欄で、閉じるボタンを持ちます。一覧にも関係を文字で出します。高倍率や大きいフォントで短縮ラベルが予約席へはみ出さないようクリップします。

読み上げ用のaccessible nameは全文ですが、実機支援技術での操作性確認はまだ行っていません。省略ラベル・拡大した印が低倍率で近接する場合は一覧と巡回を使います。
