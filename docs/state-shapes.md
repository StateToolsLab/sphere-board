# 状態の形の割り当て — v0.4.0

状態の形は `app/states.js` の `definitions` に集約し、World / Brand / Light / Dark では変更しません。状態を色で表さず、単色の線形だけで判別できることを優先します。レーン色は別の意味として残します。

v0.4.0 では小さな表示でも輪郭が崩れにくいよう、細かな装飾より「円・雪印・矢印・紙・箱・カレンダー・疑問符」など、外形と主要ストロークが違う記号へ寄せました。通常状態15個とゲート結果6個は、表示上のSVG pathが21個すべて異なります。通常状態とゲート結果で同じ語になる「凍結」「中止」だけは、ゲート文脈では菱形を基調にした別の内側形を使います。Starter の state 語彙自体は増やしていません。

## 状態15語

| state | 日本語 | 形 | 判断 |
|---|---|---|---|
| not_started | 未着手 | 中空の円 | まだ始まっていない空の器として最小の輪郭にした。 |
| in_progress | 進行中 | 円＋右向き矢印 | 未着手の円を残しつつ、進む方向を一本加えて差を明確にした。 |
| frozen | 凍結 | 六方向の雪印 | 停止線ではなく凍結そのものを想起しやすい放射形にした。 |
| carried_over | 持越し | 折れ矢印＋下線 | 先へ送り、別の区切りへ持ち越す意味を折れと下線で示した。 |
| spanning | 跨り | 交差する二つの輪 | 二つの範囲にまたがることを重なりだけで示した。 |
| returned | 回収済 | 受け皿へ降りる回収矢印 | 戻るだけでなく「回収先へ収まる」ことを下線の受け皿で区別した。 |
| handed_over | 引き継ぎ済 | 境界を越える右矢印 | 二本の境界を越えて次へ渡したことを示した。 |
| record_only | 記録のみ | 折り返し角のある紙 | 作業状態より記録物であることを紙の外形で示した。 |
| off_mainline | 本線外 | 本線から分岐する矢印 | 縦の本線から外へ逸れる一本の枝として示した。 |
| cancelled | 中止 | 八角形＋交差線 | 強い停止の外形とXを組み合わせた。 |
| discarded | 廃棄 | ふた付きの廃棄箱 | 中止とは異なり、成果物を捨てる意味を容器で示した。 |
| out_of_scope | 対象外 | 斜線を引いた円 | 一般的な対象外の記号として、円と斜線にした。 |
| scheduled | 予定 | 日付点のある予定表 | 未来の配置であることをカレンダーとして示した。 |
| none | 状態なし | 短い一本線 | 「意味のある状態記号がない」ことを最小の線で示した。 |
| unknown | 不明 | 疑問符＋点 | 情報不足と一目で分かる疑問符にした。 |

## ゲートの6結果

| state | 日本語 | 形 | 判断 |
|---|---|---|---|
| pending | 未 | 砂時計 | 判定待ちを時間の記号で示した。 |
| passed | 通過 | 大きなチェック | 最小の肯定記号として大きく単純なチェックにした。 |
| passed_with_defects | 通過(瑕疵) | チェック＋注意の縦印 | 通過を残しつつ、瑕疵を別の縦印で追加した。 |
| sent_back | 差し戻し | 左へ折り返すUターン矢印 | 回収済の「受け皿」と混同しないよう、左へ戻す方向だけを強調した。 |
| frozen | 凍結 | 菱形＋停止十字 | 通常の雪印と分け、ゲートが止まっていることを菱形文脈で示した。 |
| cancelled | 中止 | 菱形＋交差線 | 通常の八角形Xと分け、ゲート判定としての中止を菱形文脈で示した。 |

## 選択・focus・その他の印

選択は実線の角枠、focus はアクセント色の点線枠にして重ねても見分けられるようにしています。現在地、Ready、妨げ、planned などは状態形とは別の補助印です。hover は状態形を変えず、関係線を薄く出して短い名前の吹き出しを表示します。

実物は `preview/v0.5.0/state-shapes-light.png` と `preview/v0.5.0/state-shapes-dark.png` で確認できます。形の最終受入は設計判断としてユーザー確認対象です。
