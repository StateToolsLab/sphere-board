# AI指示へのブリッジ

利用中のAIのプロジェクト指示に、同梱ブロックを追記してください。既存ファイルを置換しません。
ファイル名は配置先の例です。製品・実行モードによって自動認識の条件が異なるため、
**必ず実際のAIへこのブロックを渡し、WORKFLOWを読めているか確認してください。**
本パッケージは各製品の自動発見やツール実行を実装・保証しません。
複数AIには同じWORKFLOWを案内し、各AIのactor IDと担当範囲を定めます。

投影に対する更新を防ぐため、ブリッジのsource判定も含めて渡してください。状態の語彙とreturnの意味はStarter 0.2のWORKFLOWを優先します。
